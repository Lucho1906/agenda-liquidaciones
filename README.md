# Agenda de liquidaciones

Página web del área de liquidaciones: calendario de reuniones y tareas, pendientes, historial y control de liquidación por contrato.

- Se abre desde cualquier navegador (computador o celular) y se puede agregar a la pantalla de inicio.
- Los datos viven en Supabase, protegidos por reglas de acceso: solo los correos autorizados pueden entrar.
- Este repositorio solo contiene la página publicada. El código fuente y los scripts de la base de datos están en el repositorio privado `Cronograma-y-calendario` (carpeta `web/`); `web/build.py` genera estos archivos.
